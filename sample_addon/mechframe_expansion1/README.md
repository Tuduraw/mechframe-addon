# Mech Frame 拡張パック1「Frontier Frames」

Mech Frame(tudursvehiclemod のロボットアドオン)の拡張パックです。
4社のメーカーと、そのパーツ42種・標準機12機を追加します。

- 前提: tudursvehiclemod(作者 Tuduraw 氏)と Mech Frame 0.6.0 以降。
- このパックのモデル・テクスチャ・データは、Anthropic の AI「Claude」を使ってスクリプトから生成しました。
  他者が権利を持つデータは使っていません。武器の効果音・弾のモデルは Mech Frame 本体の物を使います。

## 導入

ゲームフォルダの `tudursvehiclemod-addons/` に、このフォルダ(`mechframe_expansion1`)をそのまま置きます。
データパックやリソースパックとしての導入は不要です。名前空間は `mfx` です。

- パーツはメック製作台で作れます(材料は下記)。
- 標準機は Mech Frame のスポナー(機体キット)の一覧に、各Tierで追加されます。

## メーカーとコンセプト

### 変形機

| 機体 | 戦闘機形態 | 変形 |
|---|---|---|
| Kite | 翼幅約7.6 m のグライダー型。最高速は低く、旋回は最も鋭い | 仰向けに寝て頭が機首(光学センサーが機首のプローブ)。脚は後ろへ伸びて閉じ、1本の桁のテールブームに。すねが外へ転がってふくらはぎのフィンがV尾翼になる。背中に2重に畳んだ細長い翼を横へ振り出し、先端のヒンジで外側の翼を開いて翼幅を倍にする |
| Corvus | 翼幅約5.2 m の全翼機 | 仰向けに寝て頭が機首のセンサーフェアリングに。脚は後ろへ伸ばしてからすねを前へ折り返し(Z折り)、かかとのスロットノズルを真後ろへ向ける。カラスの畳んだ翼のような2重の翼板を30度後退させて開き、外側の板を前へ開いて翼弦を倍にする |
| Condor | 翼幅約6.5 m の重ガンシップ | 仰向けに寝て兜が機首に。脚は後ろへ伸ばして閉じ、すねを90度転がしてふくらはぎの板を水平尾翼にする。背中の厚い翼板を横へ振り出し、外側の板を開く。内側の翼板に横たえていたエンジンナセルが前を向く |

パーツの材料は「Tierの素材」「メーカーの素材」「箇所ごとの追加材料」です。

| 4・5 | ダイヤモンド(+鉄インゴット2) | | Talos | 鉄ブロック |

| 箇所 | Tierの素材 | メーカーの素材 | 追加 |
|---|---|---|---|
| 頭部 | 2 | 1 | ガラス1 |
| コア | 5 | 2 | レッドストーンブロック1 |
| 腕部 | 4 | 2 | |
| 脚部 | 6 | 2 | |
| ブースター | 4 | 2 | ファイヤーチャージ2 |
| 武器 | 3 | 1 | 火薬2、レッドストーン1 |

- 変形セットのパーツは、さらにファントムの皮膜2を使います。
- 内蔵武器(WI-X2 Arbalest Rail)は単体では作れません(腕部 AM-X2 Arbalest に含まれます)。

## 再生成

Mech Frame のソースの `tools/mechgen/packs/mfx/build_pack.py` で、このフォルダ全体を作り直せます(meshkit 0.4.1 が必要)。
